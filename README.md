# 🚀 StreamForge

A Real-Time Event Streaming Platform built using Apache Kafka, FastAPI, PostgreSQL, and React.

---

## 📌 Project Overview

StreamForge is designed to demonstrate a complete real-time event streaming pipeline.

Events generated by producers are published to Apache Kafka, consumed by backend services, stored in PostgreSQL, and visualized through a React dashboard.
